# WolfDrive View Metadata Taxonomy

## 📁 Physical / File View
- **System Attributes**: File Name, File Path, File Size, Extension, MIME Type, Permissions, Inode
- **Timestamps**: Date Created, Date Modified, Date Indexed, Last Accessed
- **Storage Attributes**: Disk Volume, Checksum (MD5/SHA256), Storage Tier

## 📷 Photo & Image View
- **Basic Info**: Title, Caption, Alt Text, Rating, Tags, Favorite Status
- **EXIF Metadata**: Camera Make/Model, Lens, Focal Length, Aperture (f-number), ISO, Shutter Speed, Exposure Bias
- **Dimensions & Format**: Width, Height, Aspect Ratio, Color Space (sRGB/P3), Bit Depth, Alpha Channel
- **Spatial Data**: GPS Coordinates (Lat/Long), Altitude, Location Name

## 🎬 General Video View
- **Basic Info**: Video Title, Description, Tags, Category, Rating
- **Media Properties**: Duration, Resolution (e.g., 4K, 1080p), Aspect Ratio, Frame Rate (FPS)
- **Encoding Details**: Video Codec (H.264/HEVC/AV1), Bitrate, Container Format (.mp4/.mkv)
- **Audio Tracks**: Audio Codec, Channel Count (Stereo/5.1), Sample Rate, Language

## 🎬 Movie View
- **Creative Info**: Movie Title, Original Title, Tagline, Synopsis, Release Year, MPAA Rating, User Rating
- **Credits**: Director, Producer, Cast (Actors & Characters), Writer, Studio/Production Co.
- **Media Properties**: Duration, Resolution, Aspect Ratio, Audio Format (Dolby Atmos/DTS-HD), Subtitle Languages
- **External Identifiers**: IMDb ID, TMDB ID

## 📺 TV & Show View
- **Show Info**: Series Title, Overview, Content Rating, Air Dates, Network/Platform, Status (Running/Ended)
- **Episode Info**: Season Number, Episode Number, Episode Title, Summary, Air Date, Duration
- **Credits**: Showrunner, Guest Stars, Director, Writer
- **Media Properties**: Resolution, Video Codec, Audio Tracks, Subtitle Tracks

## 📚 Book Audio & eBook View
- **Bibliographic Data**: Book Title, Subtitle, Author(s), Editor, Translator, Series Name, Volume/Book Number
- **Publishing Info**: Publisher, Publication Date, Language, ISBN-10 / ISBN-13, Edition
- **Narrator**: Name, Performance Style, Audio Format (e.g., Stereo/5.1)
- **Reading Metadata**: Page Count, Chapter Count, Word Count, Description/Blurb, Genre/Subjects
- **User Progress**: Last Read Position (CFI), Progress Percentage, Highlights Count, Bookmark Count

## 🎵 Music & Audio View
- **Track Info**: Track Title, Track Number, Disc Number, Duration, Explicit Flag, Genre, Release Year
- **Release Info**: Album Title, Album Artist, Composer, Performer, Publisher/Label, ISRC
- **Audio Stream Info**: Bitrate (kbps), Bit Depth, Sample Rate (kHz), Channels, Codec (FLAC/MP3/AAC), Lossless Flag
- **Embedded Media**: Cover Art (Front/Back), Lyrics (Unsynced/Synced)

## 📄 Document View (PDF, MD, Office)
- **Document Info**: Document Title, Subject, Author/Creator, Keywords, Abstract/Summary
- **PDF Properties**: Page Count, PDF Version, Encrypted/Password Flag, Producer Software (e.g., LaTeX, Word)
- **Text & Structure**: Word Count, Character Count, Reading Time Estimate, Table of Contents Tree
- **User Progress**: Last Page Viewed, Zoom Level, Annotations/Comments Count

## 🎮 Game View
- **Game Info**: Game Title, Overview/Summary, Franchise, Release Date, ESRB/PEGI Rating, User Rating
- **Platform & Technical**: Platform/System (e.g., PC, Switch), Developer, Publisher, Genre, Game Engine
- **Emulation & ROM Info**: ROM/ISO Name, Region (NTSC/PAL), Version/Revision, CRC32/MD5 Checksum
- **External Identifiers**: IGDB ID, RAWG ID

## 💻 Software & Application View
- **App Info**: Application Name, Developer/Vendor, License Type (MIT, Commercial), Category
- **Technical Info**: Target Platform/OS, Architecture (x86_64, arm64), Application Version, Build Number
- **Package Details**: Binary Path, Dependencies, System Requirements, Digital Signature Status
