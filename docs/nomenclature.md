
# Data Organization Nomenclature

**Taxonomy Rules**:
* **Container**: High-level virtual grouping (cross-entity or user-curated).
* **Grouping**: Domain-specific structural grouping (albums, series, projects).
* **Entity**: Primary metadata object.
* **Item**: Individual playable, readable, or executable media unit.

---

### 📁 Physical / File View (Default)
- UI: Files
- **Root Directory / Drive**
  - **Folder / Subfolder**
    - **File Name** `[Extension]`

### 📷 Photo & Image View
